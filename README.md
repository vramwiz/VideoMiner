# VideoMiner

## 動画編集者向けチェック機能

VideoMiner には、動画の確認作業中に気になる位置を記録し、あとから戻りやすくするためのチェック機能があります。

### 手動チャプター

- 下側ツールグループの `+` で、現在位置に手動チャプターを追加できます。
- 下側ツールグループの `-` で、現在位置に近い手動チャプターを削除できます。
- 手動チャプターはシークバー上に緑のマーカーとして表示されます。
- 手動チャプターは動画ファイルごとに保存され、同じ動画を開いた時に復元されます。

### 自動チェック

- 下側ツールグループの `Check` を有効にすると、再生中に映像と音声を軽量チェックします。
- 検知した候補はシークバー上にマーカーとして表示されます。
- 黄色は注意、赤は危険度が高い候補です。
- 自動チェックのマーカーは一時的な候補扱いで、保存対象にはしていません。

現在の自動チェックでは、以下の候補を検知します。

- 黒フレーム
  - フレーム四隅の暗さから、無表示に近い区間を検知します。
  - 短い候補は黄色、長めの候補や終端付近の候補は赤になります。
- 無音区間
  - 音声トラックの無音が続く区間を検知します。
  - 動画冒頭の無音は、画面録画などで自然に発生しやすいため黄色に抑えます。
- 左右チャンネル異常
  - 左だけ無音、右だけ無音、左右の音量差が極端な区間を検知します。
- フレーム差分異常
  - 前後のフレームは似ているのに、1 フレームだけ大きく違う候補を検知します。
  - 通常のシーン切替では反応しにくいよう、黄色候補として控えめに扱います。
- 音量急変
  - 前後の音声ブロックと比べて、音量が急に大きくなる、または小さくなる候補を検知します。
- クリッピング
  - 音声ピークが上限付近に張り付いた、音割れ候補を赤で検知します。

### チャプター移動とループ

- `Ctrl+Left` / `Ctrl+Right` で、前後のチャプター、先頭フレーム、終了フレームへ移動できます。
- 再生終了時動作を `Loop` にすると、現在位置を含むチャプター区間を繰り返し再生します。
- 例: `先頭 - A - B - 終了` の構成で A と B の間から再生した場合、B まで再生したあと A に戻ります。

### 外部更新の自動再読み込み

- 開いている動画ファイルのフォルダを監視し、現在の動画が外部アプリで更新された場合に検知します。
- 動画編集アプリなどが上書き出力中に何度もファイルを更新しても、更新が落ち着くまで待ってから 1 回だけ処理します。
- 更新が確定すると、現在開いている動画を読み込み直し、先頭フレームを表示します。
- `Check` の ON/OFF や音量などの設定状態は維持します。
- 自動チェックで付いた一時的な警告チャプターは、再読み込み時に削除されます。
- 手動チャプターは動画ファイルごとの保存状態から復元されます。

VideoMiner は、動画ファイルをフォルダ単位で続けて確認するための Windows 用ビューアです。

通常のメディアプレイヤーのように 1 ファイルずつ開くのではなく、開いた動画と同じフォルダ内のファイルを作業対象として扱い、前後の動画へ素早く移動できます。同じフォルダ内の動画は作成日時の古い順に並びます。素材確認、動画確認、フォルダ内の連続チェックを軽く行うためのアプリです。

最新版は GitHub Releases からダウンロードしてください。

リリースには、用途に応じて複数のファイルがあります。

| ファイル | 内容 | 使い方 |
| --- | --- | --- |
| `VideoMiner_Setup.exe` | インストーラ本体 | 通常はこちらを実行してインストールします。 |
| `VideoMiner_Setup.zip` | インストーラを ZIP にしたもの | ブラウザや環境によって `.exe` を直接扱いにくい場合はこちらを展開して使います。 |

どの形式にも、実行に必要な FFmpeg DLL と GPL-3.0 のライセンス文書を含める想定です。

## 主な特徴

- 動画ファイルの再生
- 開いたファイルと同じフォルダ内の前後動画へ移動
- フォルダ内動画は作成日時の古い順でナビゲーション
- ファイルのドラッグ&ドロップ対応
- 動画上に重ねて表示される再生、シーク、音量、ミュート操作
- 再生終了時の動作を `Stop` / `Loop` / `Next` から切り替え
- ループ再生や再生中シークで、できるだけ開き直さず素早く再開
- シーク直後や短い動画の開始直後に古いフレームや戻りフレームを表示しにくい安定したデコード処理
- 透過情報を持つ `.mov` の再生に対応し、透明部分は市松模様で確認可能
- 同一フォルダ内動画のサムネイル一覧表示
- サムネイル一覧からクリックで動画を切り替え
- サムネイル一覧のディスクキャッシュ、ホイールスクロール、キーボード選択、右下ボタン/中央ボタン+ホイール拡大縮小、ホバー中の音なしプレビュー
- 全画面表示
- マウスホイールによるズーム
- 拡大中のドラッグ移動
- 画面左右端のオーバーレイから前後動画へ移動
- マウスジェスチャーで動画を一時的に隠すボスが来たモード
- 前回開いたファイルやウィンドウ位置の保存

## 基本操作

| 操作 | 内容 |
| --- | --- |
| `Ctrl+O` | ファイルを開く |
| `Space` | 再生/停止 |
| `Left` / `Right` | 前後の動画へ移動 |
| `PageUp` / `PageDown` | 前後の動画へ移動 |
| `Ctrl+Left` / `Ctrl+Right` | 前後のチャプター、先頭、終了フレームへ移動 |
| `Home` / `End` | 先頭/末尾付近へ移動 |
| `Up` / `Down` | 音量を変更 |
| `M` | ミュート切り替え |
| `F11` | 全画面切り替え |
| `Esc` | 全画面解除 |
| `Tab` | サムネイル一覧の表示/非表示 |
| 動画面クリック | 再生/停止 |
| 動画面ダブルクリック | 全画面切り替え |
| 動画面右クリック | サムネイル一覧を表示 |
| マウスホイール | 動画表示部分の拡大/縮小 |
| シークバー上でマウスホイール | 通常時は 1 秒単位、`Check` 中は 1 フレーム目安で移動。再生中は一時停止して移動 |
| 左ドラッグ | 拡大中の表示位置移動 |
| 画面左右端クリック | 前後の動画へ移動 |
| サムネイルクリック | その動画へ切り替え |
| サムネイル一覧で矢印キー | 選択中タイルを移動 |
| サムネイル一覧で `Enter` | 選択中の動画へ切り替え |
| サムネイル一覧で右クリック | サムネイル一覧を閉じる |
| サムネイル一覧でマウスホイール | 一覧を縦スクロール |
| サムネイル一覧右下の `+` / `-` | サムネイルを拡大/縮小 |
| サムネイル一覧で中央ボタンを押しながらマウスホイール | サムネイルを拡大/縮小 |
| サムネイル一覧でホバー | 操作対象のタイルを強調表示し、少し待つと音なしプレビューを表示 |

## 設定ファイル

VideoMiner は、ユーザー設定を次の場所に保存します。

```text
%APPDATA%\VideoMiner\VideoMiner.ini
```

サムネイルサイズは `%APPDATA%\VideoMiner\VideoMiner.ini` に保存され、次回起動時にも復元されます。

アンインストールしても設定ファイルは残る場合があります。不要な場合は、このフォルダを手動で削除してください。
